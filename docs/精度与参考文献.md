# 精度与参考文献

> 这份文档回答两个问题：
> 1. **测试里的"真值"是怎么来的？**（`tests/reference_values.py` 里那些数字）
> 2. **14 条公式各自的原始出处是哪篇论文？**
>
> 它同时是 README「实测能力与精度」一节的依据。凡是**没能核实到原文**的，这里都明确标注，
> 不装作查过了。

---

## 一、先说清楚：这个项目里有两类"出处"

很容易把这两件事混在一起，所以先分开：

| | 是什么 | 在本项目里扮演什么角色 |
|---|---|---|
| **① 参照值（真值）** | 权威机构发布的饱和水汽压表 / 湿球温度定义式 | 测试拿它当"正确答案"，用来判断 14 条公式算得准不准 |
| **② 公式出处** | 14 条公式各自的原始论文 | 说明每条公式的系数是谁、哪一年提出的，以及它的宣称适用域 |

**参照值与公式出处必须是两套独立的来源。** 如果拿 A 公式的输出当真值去检验 B 公式，
那只是"两个公式互相自证"——审计报告第 4.8 节把这叫"自检在构造上发现不了继承来的偏差"，
本项目 v1.3.0 以前的 `core.py` 自检正是这么写的（对照自己上一版的输出）。

## 二、项目实际使用的参照值（真值）

| 用途 | 参照来源 | 用在哪 |
|---|---|---|
| 饱和水汽压（水面与冰面） | **WMO / Smithsonian 气象表**常用值；与 Goff-Gratch (1946)、Murphy & Koop (2005) 在该区间内互差 < 0.1% | `tests/test_esat_reference.py` 全部 14 条公式 |
| 湿球温度的**严格定义** | **ASHRAE 绝热饱和（adiabatic saturation）方程** | `tests/test_solver.py::ashrae_wetbulb` |
| 湿球温度的第二来源 | **Stull (2011)** 经验式（独立实现，零共享代码） | `tests/test_solver.py::test_wetbulb_matches_stull_2011` |
| 露点温度 | **ASHRAE / Vaisala 湿度换算表** | `tests/test_solver.py::DEWPOINT_REF` |

### 为什么这张表能自证"表本身是对的"

Goff-水面、Goff2-水面（Goff-Gratch 1946）、Wexler-水面 是三条**公认参考级**的独立公式。
它们对同一张表的偏差都 ≤ 0.09%——如果表本身错了，三条公式会一起偏，不会同时贴合。
**"表"与"公式"互相印证，而不是自说自话。**

反过来，Table 里最大的偏差出现在 `Arden-水面`（100 ℃ 时 +12.7%），
那是公式的截断误差（见「已知限制」），不是表的误差。

## 三、方法论（可复现）

1. **饱和水汽压**：对每条公式，在其**注册适用域 ∩ 参考表可得点**上逐点比较相对偏差，
   记录最大偏差与出现位置。取样点见 `tests/reference_values.py::WATER_REF` / `ICE_REF`。
2. **解析导数**：与**中心差分**比较（`h = 1e-4`），相对误差阈值 `1e-6`。
   这一步是独立的：导数错了但根不错的情况，只看"结果对不对"永远发现不了
   ——v1.3.0 的 goff 族就是这个毛病（最大偏差 40%）。
3. **湿球温度**：
   - 与 ASHRAE 绝热饱和定义式比（二分求解，容差 0.5 K）；
   - 与 Stull (2011) 经验式比（容差 1.0 K，粗查用）；
   - 还要满足**湿球方程残差 < 1e-3 hPa**（结果必须真的解出方程，而不只是"看起来合理"）。
4. **露点温度**：与公开湿度换算表比（容差 0.3 K），并做**往返自洽**检验
   （`e_sat(求出的露点)` 必须等于实际水汽压）。
5. **容差怎么定的**：先实测，再把容差设在实测之上一点点。写在
   `tests/reference_values.py::WATER_TOL` / `ICE_TOL`，每个数字旁边都有注释说明它为什么是这个值。

**为什么容差不是"统一 0.1%"**：14 条公式分两类——
参考级拟合式（Goff / Goff-Gratch / Wexler，容差 0.2%）与实用经验近似式
（Magnus / Buck / Tetens / August，容差 0.5%）。用同一个阈值会逼着人放宽到最差的那条，
反而失去意义。

## 六、存疑与未能核实（诚实清单）

按"这份文档的可信度边界"排列：

1. **`Gili-水面` 的原始文献没能取得。** 本项目把它的前因子从 `980.66` 改成了 `1013.25`，
   依据是两条自洽性论证，**不是原文**：
   - (a) 该式参考点是 373.16 K（水沸点），饱和水汽压按定义 = 1 atm = 1013.25 hPa；
     `980.66` 恰好是 1 工程大气压（1 at）的 hPa 数，疑为单位混淆；
   - (b) 替换后与公开参考表的偏差从 −3.04% 降到 ≤0.28%。
   **如果你能拿到原文（中文气象学期刊），请核对一遍。** 结论写在 `src/core.py` 的注释里。

2. **`Marti-冰面` 的出处没查到。** 系数与常见融雪模型中的 Marti 式一致，
   但没能确认原始文献。它的实测偏差（−50 ℃ 时 +1.29%）已写进 README。

3. **`Goff-水面` 与"Goff 1965"的卷期页未逐字确认。** 系数形式与 WMO-No. 8 附录 4.B
   推荐的 Goff 形式一致（以 273.16 K 为参考温度），这一条是确定的。

4. **`L_v` 四次多项式的系数来源不明。** 它在 0–100 ℃ 区间与公认值吻合（25 ℃ 时 2440.5 kJ/kg，
   公认约 2441.8 kJ/kg，差 0.05%），但没找到它是从哪篇文献拟合来的。
   这是"能用但说不清出处"的量，建议后续换成有出处的表达式。

5. **"湿度计方程"的 A 系数**：本项目用 `0.000667`，WMO 常用写作 `0.00066`。
   两者的物理来源是 `A ≈ c_p /(ε·L)`（约为 6.46×10⁻⁴），因此 `0.00066` 与 `0.000667`
   都在同一量级；实测与 ASHRAE 严格定义式相差 0.01–0.45 K，已在 README 中量化。

6. **`About` 对话框里原有的一条文献**：
   「周西华, 梁茵 等 (2007). 饱和水蒸气分压力经验公式的比较[J]. 辽宁工业技术大学学报, 26(3), 331-333.」
   —— 这是作者原本就列出的。**刊名疑似应为《辽宁工程技术大学学报》**（未见《辽宁工业技术大学学报》），
   建议核对后更正。本项目未改动其原文，只是把这条和上面这些一起写进了关于框。

7. **参考表本身的形式**：本项目用的是常用表值（0.01 hPa 量级精度）。
   若要与 WMO 当前推荐的公式**逐位**比对，应改为直接实现 Murphy & Koop (2005)
   或 WMO-No. 8 附录 4.B 的公式——那一步还没做。

## 七、一句话结论

- **判断公式准不准**：靠 WMO/Smithsonian 参考表 + ASHRAE 湿球定义 + Stull 经验式。
  这三样都在本项目之外，所以是"外部参照"而不是自证。
- **判断公式是谁写的**：靠上表。14 条里 **7 条已核实到可引用条目**，
  **4 条待补卷期页**，**2 条（Gili、Marti）未能取得原文**，已在第四节逐条标注。
- 凡是标"未能核实"的，README 的精度表里也照实写了它的偏差——
  **没有出处的公式不等于不能用，但必须写明它有多准、依据是什么。**
