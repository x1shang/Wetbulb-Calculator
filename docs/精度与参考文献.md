# 精度与参考文献

> 这份文档回答两个问题：
> 1. **测试里的"真值"是怎么来的？**（`tests/reference_values.py` 里那些数字）
> 2. **14 条公式各自的原始出处是哪篇论文？**
>
> 它同时是 README「实测能力与精度」一节的依据。
> 凡是**没能核实到原文**的，这里都逐条标注，不装作查过了。
>
> **核实方法**：文献条目经 Crossref / 期刊官网逐字段核对（作者、年份、刊名、卷、期、页）；
> 标"已核实"的条目都拿到了可点开的来源。WMO-No. 8 的公式条款是逐字读取原文核对的。

---

## 一、先说清楚：这个项目里有两类"出处"

很容易把这两件事混在一起，所以先分开：

| | 是什么 | 在本项目里扮演什么角色 |
|---|---|---|
| **① 参照值（真值）** | 权威机构发布的饱和水汽压表 / 湿球温度定义式 | 测试拿它当"正确答案"，判断 14 条公式算得准不准 |
| **② 公式出处** | 14 条公式各自的原始论文 | 说明每条公式的系数是谁、哪一年提出的，以及它宣称的适用域 |

**参照值与公式出处必须是两套独立的来源。** 拿 A 公式的输出当真值去检验 B 公式，
只是"两个公式互相自证"——审计报告第 4.8 节把这叫"自检在构造上发现不了继承来的偏差"，
本项目 v1.3.0 以前的 `core.py` 自检正是这么写的（对照自己上一版的输出）。

> **Stull (2011) 的性质**（取自 NCL 官方函数文档对原摘要的转引）：
> 适用 RH 5–99%、T −20~50 ℃、**气压固定 1013.25 hPa**，误差范围 **−1 ~ +0.65 ℃**，
> 平均绝对误差 < 0.3 ℃。本项目与它的实测最大差是 **0.91 K**——
> 落在 Stull 自己声明的误差带内，说明这个差主要是**它的**拟合误差，不是本项目的。
> 它在本项目里的作用是"粗查"（抓量纲/符号/3% 级系统偏差），精度声明由 ASHRAE 那一栏承担。

### 为什么这张表能自证"表本身是对的"

Goff-水面、Goff2-水面（Goff-Gratch 1946）、Wexler-水面 是三条**公认参考级**的独立公式。
它们对同一张表的偏差都 ≤ 0.09%——如果表本身错了，三条公式会一起偏，不会同时贴合。
**"表"与"公式"互相印证，而不是自说自话。**

## 三、方法论（可复现）

1. **饱和水汽压**：对每条公式，在其**注册适用域 ∩ 参考表可得点**上逐点比较相对偏差，
   记录最大偏差与出现位置。取样点见 `tests/reference_values.py::WATER_REF` / `ICE_REF`。
2. **解析导数**：与**中心差分**比较（`h = 1e-4`），相对误差阈值 `1e-6`。
   这一步是独立的：导数错了但根不错的情况，只看"结果对不对"永远发现不了
   ——v1.3.0 的 goff 族就是这个毛病（最大偏差 40%）。
3. **湿球温度**：
   - 与 ASHRAE 绝热饱和定义式比（二分求解，容差 0.5 K）；
   - 与 Stull (2011) 经验式比（容差 1.0 K，粗查用）；
   - 还要满足**湿球方程残差 < 1e-3 hPa**（结果必须真的解出方程，而不只是"看起来合理"）。
4. **露点温度**：与公开湿度换算值比（容差 0.3 K），并做**往返自洽**检验
   （`e_sat(求出的露点)` 必须等于实际水汽压）。
5. **容差怎么定的**：先实测，再把容差设在实测之上一点点。写在
   `tests/reference_values.py::WATER_TOL` / `ICE_TOL`，每个数字旁都有注释说明理由。

**为什么容差不是"统一 0.1%"**：14 条公式分两类——参考级拟合式（容差 0.2%）与
实用经验近似式（容差 0.5%）。用同一个阈值会逼着人放宽到最差的那条，反而失去意义。

## 六、存疑与未能核实（诚实清单）

### 1. `Gili-水面`：原始文献查无此名，且常数项来源不明 ⚠️

搜过的查询（中英文，均无果）：`吉利公式 饱和水汽压 湿球`、`"吉利公式" 湿球温度`、
`饱和水汽压 经验公式 "吉利" 大气物理学 教材`、`"0.00141966"`、`"3.142305" 冷却塔`、
`"3.142305" 饱和水蒸汽`、`"Gili" saturation vapour pressure "3.142305" 373.16`。
**气象学文献与教材中都没有"吉利公式"这个名称。**

**唯一找到的线索**（中文暖通/冷却塔工程文献，**不是气象学**）：
某中文论文的公式形如

```
lg P = 2.0057173 − 3.142305(10³/(t+273.15) − 10³/373.15) + 8.2·lg(373.15/(t+273.15)) − 0.0024804(100 − t)
```

其中 **`2.0057173 = lg 101.325`，P 的单位是 kPa**。

**这条线索恰好证实了 v1.3.1 修的那个 bug**：原式的参考值是 **101.325 kPa = 1013.25 hPa**
（即 1 atm），而旧版写的前因子 980.66 hPa 是 **1 工程大气压（1 at）** 的数值——
单位混淆的判断成立。换算到 hPa 制，前因子就是 **1013.25**，与 v1.3.1 的改法一致。

**但还有一个新问题（本项目尚未处理）**：本项目的指数里多出一个
`+0.00141966` 项，**这一项在任何文献里都查不到出处**（中文文献版本没有它）。
它的效果是把结果整体放大 10^0.00141966 ≈ **1.00327 倍**。实测：

| 温度 | 参考值 | 现行（含 0.00141966） | 去掉该项 |
|---|---:|---:|---:|
| 0 ℃ | 6.112 | 6.1230 (+0.180%) | 6.1030 (−0.147%) |
| 10 ℃ | 12.272 | 12.3029 (+0.252%) | 12.2628 (−0.075%) |
| 15 ℃ | 17.039 | 17.0860 (+0.276%) | 17.0303 (−0.051%) |
| 20 ℃ | 23.388 | 23.4303 (+0.181%) | 23.3538 (−0.146%) |

**最大偏差：现行 0.276% → 去掉该项 0.147%。** 见第 ⑨/第 4 节，这是一个"要不要做"的判断，
不做也不影响使用。

### 2. 湿球方程的 A 系数：本项目用的不是 WMO 的系数 ⚠️

- 本项目（以及 v1.2.x～v1.3.1 的全部历史版本）用的是
  `A = 0.000667(1 + 0.00115·t_w)`。
- 这个形式的出处是 **FAO《Frost Protection》附录 3 (A3.10)**，转引 **Fritschen & Gay (1979)**，
  **不是 WMO-No. 8**。WMO-No. 8 Annex 4.B.8 给的是 Assmann 式
  `A = 6.53×10⁻⁴(1 + 0.000944·t_w)`（水面）/ `5.75×10⁻⁴`（冰面）。
- 理论值 `A ≈ c_p/(ε·L)` ≈ 6.46–6.47×10⁻⁴（Simões-Moreira 1999），
  所以两套系数的量级都对，但**数值不同**。

实测把 A 换成 WMO 的 Assmann 值之后，与 ASHRAE 绝热饱和定义式的偏差：

| | 现行 A | 换成 WMO A |
|---|---:|---:|
| 与 ASHRAE 定义式的最大偏差 | **0.452 K**（50 ℃/RH 10%） | **0.265 K** |

**改善约 41%。** 但**不建议在没有判断的情况下直接改**：WMO 对水面与冰面给了**两个不同的 A**
（6.53e-4 / 5.75e-4），而本项目目前不区分相态——湿球在 0 ℃ 以下该用哪个，
是**降水相态**研究本身要回答的问题，属于你的专业判断范围。详见 `docs/改进操作说明书.md`。

## 七、一句话结论

- **判断公式准不准**：靠 WMO/Smithsonian 参考表 + Murphy & Koop (2005) + ASHRAE 湿球定义 +
  Stull (2011)。这四样都在本项目之外，所以是"外部参照"而不是自证。
- **判断公式是谁写的**：14 条里 **6 条已完全核实到可引用条目**（含 Magnus 水面/冰面
  逐字来自 WMO-No. 8 Annex 4.B、Marti 来自 Marti & Mauersberger 1993），
  **7 条部分核实**（缺卷期页或原文），**1 条（Gili）未能核实**。
- 两处**已知的、可量化但尚未处理**的改进：Gili 的 `0.00141966`（0.276% → 0.147%）
  与湿球 A 系数（0.452 K → 0.265 K）。两条都写进了操作说明书，等你判断。
- **没能核实的公式不等于不能用，但必须写明它有多准、依据是什么**——
  README 的精度表里，每一条的实测偏差都照实写了。
