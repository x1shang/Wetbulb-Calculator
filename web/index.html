版本号怎么读

网页版用 2.x.y，桌面版用 1.x.y，两者刻意不同号： 网页版 v2.0.0 对应桌面版 v1.3.5； 桌面版升到 1.3.6 时，网页版内核跟进则记作 2.0.1。 这样一眼就能看出"网页版是不是落后了"。
仓库的 git tag **只有桌面版这一套**（v1.x.y）：网页版的 2.x.y 不单独打 tag，而是写在同一次 Release 的说明里 —— 一个仓库挂两套 tag 比混号更容易让人迷路。

数值自检

尚未运行

与桌面版的有意差异

  • 界面布局完全重做：桌面版受 PySide2 布局约束，网页版按液态玻璃风格重新排布，但术语、模式名、单位、状态文案与桌面版一一对应。
  • 切换模式 / 改单位不再清空输入框：桌面版会清空（clearall()），这里保留已填数值，因为标签会跟着模式变，不会误解。
  • 结果表头按模式正确书写：桌面版在「已知湿球求露点」模式下表头仍写「| 相对湿度」，属措辞瑕疵，这里按模式语义更正。
  • 迭代图是可交互 SVG：桌面版弹独立的 matplotlib 窗口；这里内嵌、可悬浮读数、可导出 PNG。纵轴与悬浮读数都写死 ℃，与桌面版 plt.ylabel('温度估计值 (°C)') 一致，不跟随上方温标 —— 曲线数据本来就是 ℃。
  • 批量计算改用浏览器内的 CSV / XLSX 导入导出：桌面版读程序目录里的 xlsx 并写 result_*；网页版没有文件系统，改为手动选择与下载。列约定（A/B/C）、Goff 水面/冰面选定规则与错误规则一致，但**导出文件本身有三处不等价**，逐条列在下面。
  • 批量导出的结果被截到 4 位小数：桌面版写完整 double（如 16.70033847913146），网页版写 16.7003。计算核心本身无差异，差异只在导出的文件里 —— 若你要拿这批数字继续算，请用桌面版。
  • 批量导出只保留 A/B/C 三列：桌面版把结果列追加到原表右侧、原样保留其余列；网页版重建一张三列输入 + 结果 + 错误列的表，D 列及其后的原始数据会丢失。
  • 批量导出的 #VALUE! 是文本而非 Excel 错误值：桌面版写的是真正的错误单元格（ISERROR() 认），网页版写的是同名字符串（肉眼相同，公式不认）。
  • 没有命令行接口：桌面版另有 WetBulbCLI（JSON 输出、退出码，便于脚本集成），网页版没有对应物。网页版是桌面版的子集。
  • 新增：数值自检、公式档案、结果卡片 PNG、JSON/CSV 导出、分享链接、记住上次设置与主题、批量 CSV 导入。
